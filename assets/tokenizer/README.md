# Tokenizer Artifacts

Trained SentencePiece binaries (`.model`, `.vocab`) are generated by:

```bash
python scripts/prepare_tinystories_sample.py
python scripts/train.py --input datasets/raw/sample.txt --vocab-size 32000
```

They are gitignored and can be reproduced from `configs/tokenizer.yaml` + the sample corpus.
`metadata.json` may be committed with experiment summaries under `experiments/ODY-0001/`.
